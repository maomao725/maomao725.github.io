💭 碎碎念2：沉淀与坚持

发表于2025-11-19|更新于2025-11-19|生活感悟
|字数总计:730|阅读时长:2分钟|阅读量:

前言

好吧，我又又又偷懒，不知道这是第几次了！下次一定要坚持写博客，把它当成我的秘密基地~

一些感悟 💡

这一个月捏，我感觉就是最大的感受就是得不断地沉淀、谦虚下去。无论如何，总有很多人比自己优秀 ✨，哪怕可能目前学的东西比别人进度可能快了，但其实可能别人的一些方面的思维是远超于自己的，这点是得好好学习的！

还有就是一定要多查资料再去问别人，不能无脑问（虽然我一直觉得自己大部分情况并没有这个情况，但是架不住有时候看资料不仔细，明明看了，但居然没发现，然后去问别人又要被自己蠢笑了…😄）

一些新的进展 🚀

学了一些大模型，比如 BERT、GPT-2，还有网络架构 Transformer，在慢慢入门。

而且也制定了一些比较好的计划 📝，但是一定要坚持，现在愈发觉得坚持是很可贵的，所以自己需要不断地坚持，而且现在有个搭子监督我，我想我会努力去完成计划，以后发博客的频率也会越来越高的。我挺想记录自己的成长的 🌱，我觉得博客是可以把我的进步进行可视化的，但得保持更新！嗯！下次一定（bushi）。等我最近把几个大模型学的差不多了，而且能自己说的很明白了，我就把我的笔记发到博客上。

之前的吴恩达机器学习的系列其实因为实习的任务搁置了，最近要重拾起来，但是策略要变。我估计会快速看知识，主要是去练习做作业。

对了，最近有个开心的事情 🎉，我给一个我喜欢的 b 站博主充电了！！！好像是第一次诶，我感觉我一直是一个挺会为知识付费的人，因为我希望我喜欢的创作者能感受到有人还在支持他，希望他能继续更新视频，我也很希望能看到他的视频，不希望他退了（关注了好一些博主都注销了账户😭）。

然后最开心的事，这个 up 主搞了抽奖给他的充电的会员们（”股东”），我，没想到，居然能在这些人中了！！！aaa，还是三本数学书？！不过有关机器学习，而且书的质量也太好了 📚，感谢 up 主，感谢编书人，我还去 GitHub 上找了系列其他的书（一个系列七本书）的电子版，打算有空好好揣摩一下，拜读一下！

（内心 OS：真的好厚啊！简直是可以把我砸死的程度，其实知识狠狠砸进我的脑子里也未尝不可 hhh😂）
